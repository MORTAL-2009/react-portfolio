# Hamza Portfolio

A React portfolio scaffold built with Vite.

## Development

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` checks the project with ESLint.

## Project structure

- `src/components/` contains portfolio section and UI component scaffolds.
- `src/data/` contains project, skill, and process data modules.
- `src/hooks/` contains reusable React hooks.
- `src/layouts/` contains the page layout.
- `src/styles/` contains global styles and animations.
- `public/images/` is for portfolio images; place the resume PDF in `public/`.
